# Logo bukmacherow

Tu wrzucasz logotypy bukmacherow uzywane na stronie w zakladce porownania i na kartach meczow.

Konwencja nazw plikow:

- identyfikator bukmachera z bazy / skryptu, np. `betclic.svg`
- jesli brakuje pliku, strona uzyje `_default.svg`

Przyklady:

- `betclic.svg`
- `bet365.svg`
- `sts.svg`

Trzymaj proporcje kwadratu. SVG albo PNG dziala tak samo jak herby druzyn.
